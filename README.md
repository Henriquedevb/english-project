# Thanksgiving: Turkeys, Traditions & TV

Interactive slide deck for an English class project about Thanksgiving — history, modern traditions, and TV references (Everybody Hates Chris, Friends, WKRP, Brooklyn Nine-Nine).

## View it live

Open `index.html` in any browser, or enable GitHub Pages on this repo (Settings → Pages → Deploy from branch `main`, folder `/root`).
